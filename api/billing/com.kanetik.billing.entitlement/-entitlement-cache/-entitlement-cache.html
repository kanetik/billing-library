billing/com.kanetik.billing.entitlement/EntitlementCache/EntitlementCache

EntitlementCache

constructor(purchasesUpdates: Flow<PurchaseEvent>, storage: EntitlementStorage, gracePolicy: GracePolicy, productPredicate: (Purchase) -> Boolean, clock: () -> Long = System::currentTimeMillis, graceTickIntervalMs: Long = DEFAULT_GRACE_TICK_INTERVAL_MS, logger: BillingLogger = BillingLogger.Noop)

Parameters

purchasesUpdates

The hot purchase-update stream — typically com.kanetik.billing.BillingPurchaseUpdatesOwner.observePurchaseUpdates. The cache subscribes inside start.

storage

Persistence layer. See EntitlementStorage for the contract.

gracePolicy

How long to keep treating the user as entitled after a FlowOutcome.Failure. Pass GracePolicy.None to disable grace.

productPredicate

Filter applied to each Purchase in an OwnedPurchases.Live / OwnedPurchases.Recovered event to decide whether it grants entitlement. Typical shapes: { it.products.contains("premium_lifetime") } for a single SKU, { it.products.any { id -> id in premiumIds } } for a SKU set.

clock

Time source. Defaults to System.currentTimeMillis. Inject a deterministic source in tests so grace-window assertions don't depend on real time.

graceTickIntervalMs

How often the periodic tick re-evaluates an active EntitlementState.InGrace state to detect grace expiry. Defaults to 60 seconds — fine-grained enough that grace never overstays by more than a minute, coarse enough to be free of cost. Set lower in tests driving a virtual clock.
