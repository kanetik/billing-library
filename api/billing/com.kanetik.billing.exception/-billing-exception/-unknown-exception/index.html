UnknownException

class UnknownException(result: BillingResult) : BillingException

Response code that PBL doesn't document. Should be vanishingly rare; the library wraps it so callers always have a typed channel.

Retry strategy: RetryType.NONE. If you see this in production, log it — Play may have introduced a new response code worth handling explicitly.
