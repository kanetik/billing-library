API reference is not generated locally

The Kanetik Billing Library's Dokka HTML output is generated by CI and copied here before mkdocs gh-deploy publishes the site.

To preview the API reference locally, run:

./gradlew :billing:dokkaGeneratePublicationHtml
rm -rf docs/api && mkdir -p docs/api
cp -r billing/build/dokka/html/. docs/api/

Then refresh this page. Or browse the docs site root and continue without the API reference.
